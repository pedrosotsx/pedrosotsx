## Desenvolvimento

Meu processo de desenvolvimento busca seguir um fluxo simples:

```text
Entender
   ↓
Planejar
   ↓
Desenvolver
   ↓
Testar
   ↓
Code Review
   ↓
Refatorar
   ↓
Entregar
```

Também utilizo **Inteligência Artificial como ferramenta de apoio**, principalmente para pesquisa, análise de problemas, exploração de soluções e revisão de código.

A utilização de IA não substitui a análise do código: procuro compreender, revisar e validar as soluções antes de utilizá-las.
