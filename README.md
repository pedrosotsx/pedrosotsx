## Sobre mim

Desenvolvedor **Java Back-end** com foco em construir aplicações organizadas, escaláveis e de fácil manutenção. Aplico na prática princípios de **POO, SOLID, Clean Code e Clean Architecture**, sempre buscando código que seja legível tanto para humanos quanto para o próximo desenvolvedor que vai mantê-lo.

Atualmente focado em solidificar minha base em **APIs REST, banco de dados relacional e arquitetura de software**, evoluindo projeto a projeto.
